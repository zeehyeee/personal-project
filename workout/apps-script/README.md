# 구글 시트 연결 방법 (5분)

바다네 곳간과 같은 방식이에요. 시트에 붙은 Apps Script를 웹 앱으로 배포하고, 앱 설정에 주소를 넣어요.

1. 구글 드라이브에서 **새 구글 시트**를 만들어요. 이름 예: `운동 기록 데이터베이스`
2. 시트 메뉴 **확장 프로그램 → Apps Script**
3. 기본으로 있는 `Code.gs` 내용을 지우고, 이 폴더의 `Code.gs` 내용을 통째로 붙여넣어요
4. 맨 위 `const TOKEN = '여기를-나만-아는-비밀번호로-바꾸세요';` 의 따옴표 안을 나만 아는 문장으로 바꾸고 저장(⌘S)
5. 오른쪽 위 **배포 → 새 배포**
   - 톱니바퀴(유형 선택) → **웹 앱**
   - 실행: **나**
   - 액세스 권한: **모든 사용자**
   - **배포** → 처음엔 권한 허용 화면이 나와요 (내 계정 선택 → 고급 → 안전하지 않음으로 이동 → 허용)
6. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사
7. 운동 기록 앱 → 톱니바퀴 → **구글 시트 연결**에 URL과 4번 비밀번호를 넣고 **연결하기**

연결하면 휴대폰에만 있던 기록(예시 제외)이 시트로 올라가고, 시트에 `sessions`, `swim_laps`, `settings` 탭이 자동으로 생겨요.

## 알아두기
- 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포** 해야 반영돼요 (URL은 그대로)
- 비밀번호는 휴대폰 브라우저에 저장돼요. 웹 앱 URL과 비밀번호를 둘 다 아는 사람만 읽고 쓸 수 있어요
- 인터넷이 끊겨도 기록은 휴대폰에 먼저 저장되고, 다음에 앱을 열 때 시트로 보내요
- 시트에서 직접 행을 고쳐도 돼요. 앱을 다시 열면 시트 내용으로 보여줘요 (열 이름은 바꾸지 마세요)
